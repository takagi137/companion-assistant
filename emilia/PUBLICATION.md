# 公开发布说明

## 配置与私人数据

只发布经过检查的源码、配置模板和素材。`.env`、`runtime.env`、`deploy.env`、`*.local.md`、`data/`、`verification/`、SQLite 文件、密钥文件及发布压缩包均不提交。Docker 构建使用白名单，也不会复制这些文件。不要在 `dist/` 中保存配置、聊天、录音或截图。

Key 仅在服务端使用；前端通过同域 API 请求。阿里云公共接口、素材来源及授权链接属于必要公开地址，不是私有服务器配置。测试中的假 Key、私网 IP、签名 URL 是安全测试夹具，不可替换成真实凭据。

## Git 历史

从既有开发仓库发布时，当前文件脱敏不等于历史脱敏。应使用经检查的当前提交导出不含 `.git` 的快照，并在新目录初始化发布仓库。不要把原开发仓库的旧提交、分支或标签推送到公开远程。后续修改继续检查暂存区和配置排除项。

## 素材与许可证

本项目原创源码采用根目录的 MIT 许可证。图片、角色设计、配音和音乐不自动适用代码许可证；发布前应分别确认分发范围。角色及官方素材权利归原权利人，AI 同人图也不代表获得角色授权。保留所有 sources.json、ASSET-SOURCES.json（如有）中的来源及权利说明。CC BY 音乐继续保留作者、来源、许可证和页面署名。

素材的具体来源和权利说明以各 sources.json 为准，不应把整个 dist/assets 标为 MIT。预设配音是公开台词，私人对话配音和录音不属于发布素材。
