# 阿罗娜的小窝

## 快速开始与私有配置

需要 Node.js 24+，没有第三方运行依赖。在项目目录复制 `.env.example` 为 `.env`，填写自己的配置后运行 `npm start`（或 `node --env-file-if-exists=.env server.mjs`）。Key、登录口令和域名都放在 `.env`；服务器地址等放在可选的 `deploy.env`，模板见 `deploy.env.example`。两个真实文件都不提交。无 Key 也可体验预设互动，联网模型功能需要 Key。

部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)，发布边界与素材说明见 [PUBLICATION.md](PUBLICATION.md)。下面的开发记录为历史状态，不代表读者的运行环境已完成部署。


## 默认简短对话（2026-10-16）

默认每轮一两句、最多 3 句，通常 20～80 字，一次回应一个重点，最多一个自然追问；介绍能力也不列长清单。普通知识与建议先简短回答，只有本轮明确要求详细、步骤或长内容时才展开；关键事实与执行回执照常保留。“有精神”只改变活泼程度，不再默认拉长篇幅。主模型、音色及历史记录配置不变。已加载到本地服务；接口测试 12 项通过，重载前后原聊天哈希一致，收紧规则后真实能力介绍回复为 57 字。

## 聊天、记事与角色联动（2026-10-16，当前实现）

## Q 版循环动作与内置互动配音（2026-10-16）

- 内置 41 条公开互动台词，Bella 中日各一份，共 82 段 WAV，位于 `dist/assets/room-voice/`。点击摸头、点心、猜拳、看雨等互动时使用已保存素材，不再调用翻译/TTS；同一句手动朗读也复用素材。首次打开不自动出声，第一次互动后响应；可关“互动配音”，中日语沿用输入区选择，默认日语。浏览器阻止播放时仍提供“点此播放”。
- `dist/preset-player.js` 仅缓存这些带内容指纹的公开配音文件。支持浏览器 Cache API 与有界内存缓存，缓存不可用时直接读取服务器素材。私人录音、自由聊天配音没有加入文件缓存；切换语言、录音、播放音乐、离开页面会停止旧声音。
- 使用内置 imagegen 生成 4 组双帧透明 Q 版图：待机眨眼、开心招手、吃布丁、猜拳准备，共 8 帧。原始 PNG 与完整提示词保存在 `dist/assets/arona-chibi/` 和其中的 `sources.json`。SVG 视口仅对齐原图帧，CSS 控制眨眼、呼吸与动作循环；支持系统减少动态效果和原动效开关。可切换 Q 版/原立绘，选择保存在浏览器。
- 选择项移入对白区；信封点击直接展开纸条；聊聊今天显示具体话题；删除没有玩法的“随便逛逛”；猜拳显示双方手势与胜负；日常收敛为看雨、休息与安静陪伴。小本本入口避免文字挤成竖排，保留此前语音自动发送和统一发送按钮。

## 小本本：记事、待办、查旧聊天（2026-10-16）

## 本机使用

当前真实聊天地址为 **http://127.0.0.1:4173/**。

在本目录执行以下 PowerShell 命令，按提示输入 Key（隐藏输入）：

```powershell
$env:PORT = '4173'
node server.mjs --key-stdin
```

已有运行实例时无需再次启动。也支持由运行环境注入 `DASHSCOPE_API_KEY` 后执行 `node server.mjs`。使用交互输入时 Key 仅留在进程内存；也可用 `npm start` 读取私有 `.env`。模板 `.env.example` 本身不会被读取，不要提交填好 Key 的配置。

## 当前行为

- 模型：`qwen3.8-max`，关闭联网时使用阿里云 Chat Completions，开启联网时使用 Responses API，开启思考（medium），流式输出最终回答。单次输出预算 8192 tokens，请求超时 180 秒。
- 完整聊天原文保存在服务器 `data/sora.sqlite`。刷新、重启服务、同一小窝换设备访问均从服务器恢复。浏览器只保留偏好、最近记录缓存和未确认发送的文字。
- 每次聊天由服务器读取上下文；前端只提交新消息，不能自行提供 system 提示词或伪造本轮模型历史。
- 最近对话直接发送给模型。未摘要记录超过 40 条或 24000 字符时，先保留最近约 24 条/16000 字符，再用同一个 `qwen3.8-max` 将较早部分与已有摘要合并，摘要不超过 6000 字符。摘要与原文分别保存，原文不会因压缩删除。
- 摘要调用关闭思考、最多输出 2500 tokens，只有达到阈值才额外调用，会产生少量模型费用。一次最多整理约 48000 字符；较大的旧记录导入可能要经过后续几轮逐步整理。生成失败时不移动摘要检查点，仍保存全部原文、提示这次只参考近期对话，后续再尝试。
- 摘要不是逐字记忆，也不是检索系统，可能遗漏细节。此版没有向量库或自动查找所有旧原文；完整记录可在“历史”里分页查看。
- “开始新对话”只新建话题，旧对话、稳定偏好和背景继续保留。历史对话可查看，每页最多 100 条，没有删除入口。
- 单人服务：同一个小窝口令的设备共享同一份聊天与记忆，不是多用户隔离系统。当前最多同时生成一条回复，避免多设备交错写入。
- 同一站点浏览器中的旧版记录会先留一份本地备份，再幂等导入历史归档。旧演示消息明确排除在模型记忆之外。不同浏览器或不同端口的旧本地记录不会自动跨源迁移。
- 停止回复会取消浏览器请求并中止上游调用；部分回复保留并标记为停止。流式回复每约 500ms 写入一次，异常退出后将未完成回复标记为停止；最后不到 500ms 的片段可能未落盘。此前已生成 tokens 仍可能计费。
- 错误明确提示，可手动重新发送；不会用预设文案冒充模型，也不会在失败后自动重复付费调用。
- 不支持的真实操作仍使用原文：“当前功能暂不适用，去找直觉哥哥加一下吧”，可复制需求自行发送。当前没有提醒、闹钟、绘图、订票或发消息工具；能力判断由模型提示词约束，不能视为对任意说法的绝对保证。
- 昵称仅用于首页欢迎语，不会额外上传。聊天内容、近期上下文和历史摘要经应用服务器传给阿里云；应用服务器保存完整聊天原文和摘要。阿里云侧数据处理以其服务条款与账户配置为准。

## 服务器部署

复用本目录后端即可，浏览器始终只访问同域 `/api/*`，不直接接触阿里云密钥。部署前把已在聊天中分享过的 Key 更换为专用 Key，并通过主机或容器的运行时机密配置注入。

必须配置：

| 变量 | 含义 |
| --- | --- |
| `DASHSCOPE_API_KEY` | 阿里云专用密钥，仅服务端 |
| `QWEN_MODEL` | 默认 `qwen3.8-max` |
| `DASHSCOPE_BASE_URL` | 默认北京地域 `https://dashscope.aliyuncs.com/compatible-mode/v1`；支持官方业务空间专属域名；应与 Key 地域匹配 |
| `NODE_ENV` | `production` |
| `APP_ORIGIN` | 最终 HTTPS 域名，如 `https://sora.example.com`，不带路径或末尾斜线 |
| `SORA_ACCESS_PASSWORD` | 至少 16 位随机口令，给妹妹进入小窝使用，与 API Key 完全不同 |
| `SORA_DATABASE_PATH` | 默认项目 `data/sora.sqlite`；服务器使用固定持久化路径 |
| `HOST` / `PORT` | 普通主机默认 `127.0.0.1` / `4173`；容器为 `0.0.0.0` / `4173` |

公开监听或生产模式缺少口令/HTTPS 域名时，服务拒绝启动。口令验证后使用 HttpOnly、SameSite=Strict Cookie（HTTPS 下 Secure），有效期七天；服务重启后需重新登录。文字聊天每分钟最多 12 次、每小时 120 次、最多 1 个同时调用；这是单进程保护，不是账单硬上限，请另在百炼设置费用提醒。

可直接由服务管理器运行 `node server.mjs`，也提供 Dockerfile（未在本机构建镜像）：

```sh
docker build -t sora-companion .
docker volume create sora-data
docker run -d --name sora-companion --restart unless-stopped \
  -p 127.0.0.1:4173:4173 \
  -v sora-data:/app/data \
  -e DASHSCOPE_API_KEY -e SORA_ACCESS_PASSWORD -e APP_ORIGIN \
  sora-companion
```

上面的 `-e` 从当前环境读取值，不要把 Key 写进命令。`sora-data` 卷必须在更新镜像、重建容器时继续挂载，不能删除；直接部署则保留固定的 `data` 目录。SQLite 文件含私人聊天，放在应用静态目录外并限制主机访问。备份请停服务后复制整个 `data` 目录（含可能存在的 WAL 文件），迁移后使用同一数据库路径。此版没有自动备份。反向代理负责 HTTPS，保留 Host；流式接口关闭缓冲，延长读取超时：

```nginx
location / {
    proxy_pass http://127.0.0.1:4173;
    proxy_http_version 1.1;
    proxy_set_header Host $http_host;
    proxy_buffering off;
    proxy_read_timeout 200s;
    client_max_body_size 7m;
}
```

当前尚未部署服务器，也未实际 iPhone 验收。角色图仍为官方角色设定板的本机预览素材，来源见 `dist/assets/assets-source.json`，公开发布前需确认素材许可或替换。

## 语音输入与回复朗读（2026-10-16）

- 聊天输入框上方点“点一下说话”开始，首次需要浏览器授权；再点“结束说话”后识别文字并追加到当前草稿，用户检查后发送。每段最多 60 秒，可随时取消。草稿放不下时保留识别结果供再次填入，不覆盖原草稿。
- AI 回复旁点“朗读”；勾选“自动朗读回复”后仅朗读此后完成的新回复。默认关闭，开关仅保存在当前浏览器。长回复自动分段，可随时停止。手机阻止自动播放时显示“点此播放”，已合成片段无需重新生成。
- 语音合成采用 qwen3-tts-flash / 萌宝 Bella 系统女声（AI 合成，非角色声优），识别采用 qwen3-asr-flash。输入框上方“配音”可选日语/中文，默认日语，选择保存在当前浏览器；切换立即停止旧配音，手动朗读和自动朗读共同使用该选择。
- 日语配音先由当前 qwen3.8-max 忠实翻译，再指定 Japanese 合成；中文原文直接指定 Chinese 合成，含日语或其他非中文内容时先转中文。界面原文、聊天记忆和麦克风识别不随配音语言改变；译文不写入数据库。长译文按语音接口长度限制分段合成并合并 WAV，不截断内容；翻译失败显示错误，允许重试或改中文，不用中文假冒日语。复用当前阿里云按量 Key，翻译和语音另有调用费用；未使用 Token Plan Key。
- 音频只在浏览器和服务端内存中短暂处理，小窝不落盘、不写聊天历史、不保存到本地缓存；录音及待朗读文字按需发往阿里云。确认发送的识别文字才进入原有聊天记忆。阿里云返回的临时音频链接只供后端下载，不交给前端。
- 离开聊天页、切到后台或关闭页面会停止录音与朗读；取消会中止进行中的请求。开始语音会关闭音乐播放器，以免收进录音或叠加播放。
- Safari 的 MP4 和 Chromium 的 WebM 录音先经浏览器 Web Audio 解码，再转 16 kHz 单声道 PCM WAV 上传。不依赖浏览器 SpeechRecognition。尚未通过实际 iPhone/设备麦克风验收；内置浏览器不支持时请使用 Safari、Chrome 或 Edge。
- 部署必须用 HTTPS（localhost 开发除外）；仅本站可请求麦克风。Nginx location 内增加 client_max_body_size 7m;，保留已有超时设置。摄像头和定位仍禁用。
- POST /api/speech/recognize 接收 audio/wav，校验文件头、采样率、实际时长及 6 MiB 大小；POST /api/speech/synthesize 接收 JSON text（每段至多 500 字）及 language（ja/zh，省略时为 ja），返回 WAV。拒绝未知语言，音色由服务端固定为 Bella。接口沿用口令及同源保护，最多一个语音处理并发，75 秒超时覆盖翻译、合成和下载。ASR 每分钟 12 / 每小时 120 次，TTS 每分钟 60 / 每小时 240 段；这些保护不代替阿里云账单限额。
- 合成音频只允许从固定的阿里云结果桶以 HTTPS 下载，不跟随重定向、不转发 Key。修正上游 WAV 的流式占位长度后返回；无文件缓存。

本轮验证：原有 19 项聊天/记忆/搜索/音乐测试通过；6 项语音后端测试通过，4 项模拟设备交互测试通过（共 29 项有效证据）。集中测试时模拟设备测试的清理顺序有误，修正后仅复验该文件；WAV 长度修正后仅复验语音接口。真实按量调用已完成“短句合成 → 合成音频识别”闭环，原有两个话题 12 + 2 条记录不变。未开启真实麦克风；浏览器访问工具仍受策略限制，自动测试和接口成功不等于手机音频播放已验收。
